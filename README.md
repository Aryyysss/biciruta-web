# BiciRuta · Web de la tienda

Web de BiciRuta S.L., tienda de bicicletas, accesorios, taller y alquiler.
Proyecto de la práctica UT 1 de Lenguajes de marcas (CFGS ASIR, 1.º).

## Estructura

```
biciruta-web/
├── index.html          ← estructura y contenido
├── css/estilos.css     ← estilos
├── js/app.js           ← comportamiento (menú y carrito)
├── img/logo_biciruta.png
├── README.md
└── .gitignore
```

## Cómo verla

1. Abre la carpeta `biciruta-web` en Visual Studio Code.
2. Abre `index.html` y pulsa **Go Live** (extensión Live Server) en la barra de estado.
3. Se abrirá el navegador en `http://127.0.0.1:5500/index.html`.
